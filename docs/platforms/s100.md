# RDK S100 开发与运行

现有 RDK 入口使用 S100 的 `nash-e`。资源、SDK、设备和结果回传配置从 `s100.local.yaml` 读取，字段见 [公开模板](../../configs/platforms/s100.yaml)。将 SDK 与运行时按实际用途配对，主机工具和目标端库分别确认架构与版本。

## 进入环境

在 Linux 编译主机的仓库根目录执行以下命令，前提是现有容器已按 [Docker 说明](../../docker/rdk_s100/README.md) 准备。

```bash
bash docker/rdk_s100/enter_container.sh
```

模型和数据集的位置由 S100 本地配置提供。模型目录和板端运行步骤见 [RDK 模型索引](../../rdk_models/README.md)。从单模型命令开始，确认该命令涉及的资源、参考评价和上传。`rdk_models/deploy/compile.sh` 与 `evaluate.sh` 是顺序运行多模型的总入口。
